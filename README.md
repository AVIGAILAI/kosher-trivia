# טריוויה קבוצתית עם גישה לפלאפונים כשרים

משחק טריוויה בסגנון Kahoot, עם דגש על **גישה לפלאפונים כשרים** (בלי אינטרנט/דפדפן):
השחקן מחייג למספר, מקיש את קוד המשחק, ובכל שאלה מקיש 1–4 — הפלאפון עצמו הוא השלט.

## מסכים
- `/` — מסך המנחה (להקרנה)
- `/controller` — שלט שחקן בדפדפן
- `/editor` — עורך שאלות (הוספה/עריכה, שמירה, כמה מאגרים)
- `/kosher-sim` — סימולטור פלאפון כשר (לפיתוח ובדיקות)
- `/voice/*` — webhooks לטלפוניה אמיתית (Twilio / ספק תואם)

## הרצה מקומית
```
npm install
npm start
```
פותחים http://localhost:3000

## פריסה (Render)
הפרויקט כולל `render.yaml`. ב-Render בוחרים **New → Blueprint**, מחברים את הריפו,
ו-Render יקים את השירות אוטומטית. השרת מאזין על `process.env.PORT`.

## חיבור מספר טלפון אמיתי
ראו [SETUP-TWILIO.md](SETUP-TWILIO.md). כתובת ה-webhook לאחר פריסה:
`https://<כתובת-האתר>/voice/incoming`

## ארכיטקטורה
- `server/gameManager.js` — ליבה גנרית (sessions, שחקנים, ניקוד)
- `server/games/trivia.js` — לוגיקת הטריוויה
- `server/telephony/` — שער טלפוני (ספק מדומה + Twilio) — שימוש חוזר מלא בלוגיקת המשחק
- `server/quizStore.js` — ניהול ושמירת מאגרי שאלות
- `public/` — ממשקי המשתמש
